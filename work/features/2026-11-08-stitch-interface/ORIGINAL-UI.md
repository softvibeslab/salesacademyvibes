# Sales Academy · interfaz original

Copia exacta de los archivos de interfaz existentes al 8 de noviembre de 2026. Este paquete es independiente de las recreaciones generadas en Stitch.

## Contenido

- growth/site/: templates HTML, CSS, JavaScript y activos públicos.
- growth/content/seed.json: contenido editorial inicial de ejemplo.
- growth/content/video-catalog.json: catálogo de las cinco películas.
- original-ui-manifest.json: lista, tamaños, SHA256 y direcciones públicas de referencia.

Se incluyen los cinco MP4, sus posters y subtítulos. Ningún original fue modificado. El contenido editorial inicial no es una descarga de la base privada ni de borradores actuales del CMS.

## Cómo usarlo

Usa los archivos como fuente para importar o reconstruir la interfaz en una herramienta de diseño, revisar los estilos o identificar el activo correcto. El sitio público de referencia es https://v5.salesacademy.softvibes.cloud/descubre/.

Este ZIP no es una aplicación lista para ejecutar: los templates necesitan el servidor original para rellenar su contenido y algunas acciones usan sus API. No incluye backend, cuentas, sesiones, claves ni datos privados. No intentes iniciar sesión, autenticar usuarios o conectar el CMS desde este paquete. Importar una pantalla en Stitch no conecta Hermes, WhatsApp ni el CMS de producción.

Para revisar la apariencia mediante imágenes usa el paquete separado salesacademy-stitch-references.zip. Las 49 referencias de ese paquete son capturas públicas o de pruebas sintéticas y se mantienen aparte del código original.

Las fotografías de escenarios son ilustraciones generadas; las pantallas de app son datos de ejemplo de una demo; los videos muestran visión conceptual. Conservar esas etiquetas al reutilizar los materiales.
