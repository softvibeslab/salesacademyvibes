# Privacidad y límites

Privacy by default. Este demo no lleva datos de cliente.

## Qué sí

- Nombres de pila de ejemplo: Ana, Luis, Mira, Teo, Jorge, Rosa.
- Leads con forma `Lead #4920`, `#302`, `#188`, `#210`, `#077`, `#441`.
- Fecha de relato: 6 y 7 de noviembre de 2026.

## Qué no

- Apellidos, teléfonos, correos o contratos reales.
- Contraseñas.
- Secretos en el repo. El JSON del VPS solo tiene el ejemplo de salas.

## Límites que no se deben romper

- El tablero y el API son un demo. El encabezado `X-Ops-Actor` no es un login.
- Home y Perfil no reportan ventas reales.
- El progreso del roadmap se pierde al recargar.
- No publicar, hacer push ni restaurar DNS sin pedirlo. Este wiki se publica porque se pidió documentación.

## Restaurar el ejemplo

En `/ops/`, como administrador, **Restaurar ejemplo** (dos toques) vuelve a v1–v6.
